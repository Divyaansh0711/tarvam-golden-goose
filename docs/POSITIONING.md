# Positioning Statement

Kivi already remembers how you speak so your words come out right; semantic memory should let it
remember what you're doing so its actions come out right. It should hold the entities, standing
instructions, and open work a user has explicitly given it — the same way phonetic memory holds a
corrected name — and nothing it has inferred from listening in. Hey Kivi's job is to act on your
behalf across the apps you already use, not to understand you as a person. Every stored fact stays
visible, per-context, and as easy to correct as a mispronunciation — because that's the trust Kivi
already earned.
